# BOOTH Shelf

> [!IMPORTANT]
> ## 📢 BOOTH Shelf 공식 Chrome 웹 스토어 배포
>
> ### [▶ Chrome 웹 스토어에서 바로 설치하기](https://chromewebstore.google.com/detail/aibjhdieagkjmcodaiopaklonjbdmbpj?utm_source=item-share-cb)
>
> **이제 Chrome 웹 스토어에서 간편하게 설치하고 자동 업데이트할 수 있습니다.** 링크를 열고 **Chrome에 추가**를 눌러 주세요.

BOOTH의 내 라이브러리·받은 기프트·무료 다운로드를 한 화면에서 검색하고, 즐겨찾기와 3계층 폴더로 정리하는 Chromium 기반 확장프로그램입니다.

현재 버전은 **1.0.5**입니다. Manifest의 기술 버전과 사용자에게 표시되는 배포 버전을 동일하게 관리합니다.

## 주요 기능

- 라이브러리·기프트·무료 다운로드 탭의 모든 페이지 일괄 동기화
- 상품명·판매자명·다운로드 파일명 검색
- 한 글자만 입력해도 부분 일치하는 한국어·영어·일본어 아바타 표기를 모두 연결하는 다국어 검색
- 위아래로 원통처럼 회전하는 구매순·이름순 기준 스위치와 오름차순·내림차순 방향 스위치
- 구매 상품·받은 기프트·무료 상품 필터
- 같은 상품 페이지에서 보유한 여러 아바타 버전과 구매·기프트·무료 항목을 카드 하나로 통합
- 즐겨찾기
- 최대 3계층 폴더 생성, 이름 변경, 부모 폴더 이동, 삭제
- 상품 카드를 사이드바 폴더로 끌어 놓는 드래그 앤 드롭 분류
- 카드의 이미지·여백을 클릭해 여러 상품을 선택하거나 해제한 뒤, 어느 카드에서 드래그를 시작해도 선택한 카드 묶음만 한 번에 폴더로 옮기는 묶음 드래그
- 선택된 카드는 흔들림 없이 살짝 떠오르는 강조 효과를 사용
- 드래그 묶음의 경계가 사이드 메뉴에 닿으면 75% 크기·75% 불투명도로 천천히 바뀌며, 개수 배지도 묶음과 함께 움직임
- 폴더에 놓지 않은 드래그는 클릭 선택으로 처리하지 않는 입력 구분
- 키보드·터치 환경을 위한 상품별 **폴더에 넣기** 버튼
- 저장된 상품·즐겨찾기·폴더 데이터를 앱 안에서 완전히 삭제
- 상품명 클릭 시 BOOTH 상품 상세 페이지 열기
- 판매자명 클릭 시 해당 판매자의 BOOTH 상점 페이지 열기
- 카드 플립으로 다운로드 파일 목록을 확인하고 선택한 파일 바로 다운로드
- 다운로드 옵션이 많을 때 카드 안에서 스크롤되는 숨김 스크롤바 목록
- 헤더의 언어 아이콘으로 한국어 → English → 日本語 UI 순환 전환
- 애니메이션 없이 즉시 전환되는 아이콘형 라이트·다크 테마 버튼과 이 기기에 저장되는 테마 설정
- 목록 끝에 가까워지면 다음 상품을 자동으로 불러오는 무한 스크롤
- 헤더의 **빨간약** 버튼으로 완료 주문의 실제 결제 금액 합계 확인
- 사이드바에서 개발자의 Ko-fi 후원 페이지 열기
- 반응형 화면, 동기화 진행 표시, 모달과 카드 애니메이션
- `prefers-reduced-motion` 접근성 설정 지원

## 설치

### Chrome 웹 스토어 설치 — 권장

1. [BOOTH Shelf Chrome 웹 스토어 페이지](https://chromewebstore.google.com/detail/aibjhdieagkjmcodaiopaklonjbdmbpj?utm_source=item-share-cb)를 엽니다.
2. **Chrome에 추가**를 눌러 설치합니다.
3. 같은 브라우저 프로필로 [BOOTH 라이브러리](https://accounts.booth.pm/library)에 로그인합니다.
4. 도구 모음에서 **BOOTH Shelf**를 누르고 **전체 동기화**를 실행합니다.

웹 스토어 설치본은 새 버전이 승인·배포되면 브라우저가 자동으로 업데이트합니다.

### GitHub Release 수동 설치

1. [최신 GitHub Release](https://github.com/KuroiineUshina/BOOTH-Shelf/releases/latest)에서 `booth-shelf-vX.Y.Z.zip` 파일을 받습니다. GitHub가 자동으로 제공하는 **Source code** 파일이 아니라 이름이 `booth-shelf-`로 시작하는 설치 파일을 선택하세요.
2. ZIP을 계속 보관할 로컬 폴더에 압축 해제합니다.
3. Chrome 또는 Chromium 기반 브라우저에서 `chrome://extensions`를 엽니다.
4. 오른쪽 위의 **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
6. 압축 해제된 `booth-shelf` 폴더를 선택합니다.
7. 같은 브라우저 프로필로 [BOOTH 라이브러리](https://accounts.booth.pm/library)에 로그인합니다.
8. 도구 모음에서 **BOOTH Shelf**를 누르고 **전체 동기화**를 실행합니다.

확장 아이콘이 바로 보이지 않으면 브라우저의 확장프로그램 메뉴에서 BOOTH Shelf를 고정해 주세요.

압축해제 확장프로그램은 선택한 폴더의 JavaScript를 그대로 실행합니다. 설치 폴더를 삭제하거나 옮기면 확장프로그램이 더 이상 로드되지 않으므로 고정된 위치에 보관하세요. OneDrive 등 동기화 폴더를 사용할 때는 폴더를 다른 사람과 공유하지 말고 계정에 다단계 인증을 설정하세요.

### 업데이트

GitHub에서 설치한 압축해제 확장프로그램은 자동 업데이트되지 않습니다. 새 Release의 설치 ZIP을 받아 기존 설치 폴더의 파일을 교체한 뒤 `chrome://extensions`에서 BOOTH Shelf의 **새로고침** 버튼을 누르세요. 저장한 상품과 폴더는 브라우저의 확장 저장소에 있으므로 같은 확장 ID가 유지되는 한 그대로 남지만, 중요한 정리 정보는 업데이트 전에 별도로 확인하는 것을 권장합니다.

## 개인정보와 권한

사용하는 권한은 다음 두 가지뿐입니다.

- `storage`: 검색용 상품 정보와 즐겨찾기·폴더 구성을 이 기기에 저장합니다.
- `https://accounts.booth.pm/*`: 로그인된 사용자의 라이브러리·기프트·무료 다운로드 페이지와, 사용자가 **빨간약**을 실행했을 때 구매 내역의 결제 금액을 읽는 선택 권한입니다. 설치할 때는 부여되지 않으며 **전체 동기화** 또는 **빨간약**을 처음 실행할 때 브라우저가 권한을 요청합니다.

저장하는 정보는 상품 ID, 상품명, 판매자명, 썸네일 URL, 상품 URL, 라이브러리/기프트/무료 다운로드 페이지 위치, 다운로드 파일명·표시 용량, 테마와 언어 설정입니다. 다운로드 파일명과 표시 용량은 로컬 검색에만 사용합니다. **빨간약** 결과는 통화별 합계·완료 주문 수·무료 주문 수·계산 시각만 이 기기에 캐시하며 주문번호와 개별 주문 내용은 저장하지 않습니다. 쿠키도 읽거나 저장하지 않습니다. 실제 다운로드 URL은 사용자가 **다운로드하기**를 열 때 BOOTH 페이지에서 다시 읽어 현재 화면의 메모리에만 잠시 유지하며 `chrome.storage.local`에는 저장하지 않습니다. 선택한 URL은 BOOTH 자체 버튼과 같은 현재 페이지 다운로드 방식으로 BOOTH에만 전달되며, 별도의 다운로드 기록 접근 권한은 사용하지 않습니다. 별도 서버나 분석 도구가 없으며 저장 데이터는 `chrome.storage.local`에만 남습니다. 브라우저 기록 삭제만으로는 확장 저장소가 삭제되지 않으므로 사이드바의 **저장 데이터 모두 삭제**를 사용하세요. 이 버튼은 저장값과 함께 BOOTH 계정 페이지 읽기 권한도 해제합니다.

저장 데이터와 링크는 로드할 때마다 스키마를 검사하며, 계정 페이지·상품·판매자·썸네일은 허용된 BOOTH 주소만 사용합니다. 명시적 콘텐츠 보안 정책(CSP)이 원격 코드, 임의 연결, 프레임과 객체 삽입을 차단합니다.

자세한 내용은 [개인정보 처리 안내](PRIVACY.md)를 확인하세요. 보안 취약점은 공개 Issue에 세부 내용을 올리지 말고 [보안 정책](SECURITY.md)의 절차로 알려주세요.

## 데이터 동작

- **구매순 오름차순**은 BOOTH 라이브러리에 표시된 페이지와 카드 순서를 그대로 사용하며, 내림차순은 이를 반대로 표시합니다.
- 정렬 기준 버튼은 구매순과 이름순을, 정렬 방향 버튼은 오름차순과 내림차순을 전환합니다. 정렬은 항상 두 버튼에 표시된 한 가지 조합으로 적용됩니다.
- 다시 동기화하면 상품 목록은 최신 상태로 교체되고, 남아 있는 상품의 즐겨찾기와 폴더 분류는 유지됩니다.
- 폴더를 삭제하면 그 폴더에 직접 들어 있던 상품과 하위 폴더가 한 단계 위로 이동하므로 정리 정보가 갑자기 사라지지 않습니다.
- BOOTH의 화면 구조가 바뀌면 동기화가 실패할 수 있습니다. 기존 로컬 데이터는 동기화가 완전히 성공하기 전까지 덮어쓰지 않습니다.
- 전체 동기화는 구매·기프트·무료 다운로드 목록과 다운로드 파일명·표시 용량을 함께 읽어 로컬 검색 색인에 저장합니다. 이전 버전에서 업데이트했다면 한 번 전체 동기화해야 무료 상품 분류와 파일명 검색을 사용할 수 있습니다.
- 카드의 **다운로드하기**를 열면 최신 라이브러리 페이지에서 실제 다운로드 URL을 다시 읽습니다. URL은 저장하지 않으며 화면을 닫으면 사라집니다. 상품 위치가 바뀌어 목록을 찾지 못하면 전체 동기화 후 다시 시도해 주세요.
- 빨간약은 구매 내역의 완료 주문을 중복 제거한 뒤 주문 상세의 `결제 금액`을 합산합니다. BOOST와 배송비 등이 포함될 수 있으며 받은 기프트는 제외됩니다. 서버 부하를 줄이기 위해 결과를 로컬에 캐시하고 사용자가 **다시 계산**을 누를 때만 갱신합니다.
- 여러 BOOTH Shelf 창에서 동기화와 데이터 삭제가 겹치지 않도록 전역 잠금을 사용합니다.
- 요청 시작 간격을 최소 300ms, 페이지 요청 동시성을 2개로 제한하며 일시적인 BOOTH 오류와 요청 제한 응답에만 지수 백오프를 적용합니다.

BOOTH의 공식 안내에 따르면 받은 선물은 라이브러리의 [기프트 탭](https://accounts.booth.pm/library/gifts)에서 확인할 수 있습니다. 또한 [BOOTH 가이드라인](https://booth.pm/guidelines)에 따라 서버에 과도한 부하를 주지 않는 범위에서 사용해야 합니다. 이 프로젝트는 pixiv 또는 BOOTH의 공식 제품이 아닌 비공식 로컬 도구입니다.

개발자를 응원하고 싶다면 앱 사이드바의 **개발자 후원하기**를 통해 [Ko-fi 후원 페이지](https://ko-fi.com/kuroiineushina)를 열 수 있습니다. 이 링크는 새 탭으로 열리며, 결제 및 개인정보 처리는 Ko-fi에서 이루어집니다.

## 개발 확인

추가 패키지 설치 없이 Node.js 내장 테스트를 실행할 수 있습니다.

```powershell
npm test
npm run check
```

UI 미리보기는 정적 서버에서 `dashboard.html?demo=1`을 열면 실제 계정 데이터 없이 확인할 수 있습니다.
