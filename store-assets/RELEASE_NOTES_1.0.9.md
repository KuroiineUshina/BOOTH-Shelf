BOOTH Shelf 1.0.9는 기존 기능을 유지하면서 라이브러리 화면을 새로 구성하고, 검색과 정리 데이터 저장의 안정성을 보완합니다.

## 선물 상품 표시

- 구매 전용 배지를 제거하고, 선물 이력이 있는 상품 카드에는 대각선 리본을 표시합니다.
- 선물 이력이 없는 무료 상품은 기존 무료 배지를 유지합니다.

## 정리 데이터 보호

- 빠른 연속 조작이나 여러 창의 작업이 서로의 즐겨찾기·폴더 배치를 덮어쓰지 않도록 저장 순서를 보완했습니다.
- 저장에 실패하면 성공으로 표시하지 않고 기존 저장 데이터를 유지합니다.
- 정상 라이브러리인지 확인되지 않는 응답은 동기화 결과로 저장하지 않습니다.
- 전체 삭제와 동기화·빨간약 계산이 겹치지 않도록 처리했습니다.
- 데모 모드의 저장·삭제는 별도 메모리에만 적용합니다.
- 백업과 복원에 같은 용량 기준(32MiB)을 적용하고, 기존 2MiB를 초과하는 정리 백업도 복원할 수 있게 했습니다.

## 다운로드와 검색

- 다운로드 파일명을 갱신하는 과정에서 열린 다운로드 카드가 닫히는 문제를 수정했습니다.
- 미지원 아바타 목록을 지원 대상으로 인식하지 않도록 설명 분석을 보완했습니다.
- 설명을 읽지 못하면 기존 색인을 유지하고 다음 동기화에서 다시 확인합니다.
- 일본어 복합 검색어에서도 입력한 전체 조건을 유지합니다.

## 동기화 속도

- 요청 시작 간격은 유지하면서 동기화 병렬 처리 수를 2개에서 최대 4개로 늘렸습니다.
- 상품 설명을 12개씩 기다리던 처리를 연속 처리로 바꾸고, 중간 저장과 다음 요청을 함께 진행합니다.
- 보유 상품과 아바타 링크의 중복 조회·HTML 분석을 합치고 완료 시 같은 결과를 다시 저장하던 작업을 제거했습니다.
- 최종 저장이 끝나야 완료로 표시합니다. 실패하면 새 작업을 중단하고 진행 중인 요청·저장을 정리한 뒤 오류를 전달합니다.

## 화면과 접근성

- SEED Design의 공통 설계 원칙을 바탕으로 헤더, 사이드바, 본문과 상품 카드의 레이아웃을 새로 만들었습니다.
- 헤더에는 브랜드와 전역 기능을, 화면 제목 옆에는 전체 동기화를, 상품 목록 위에는 검색·정렬 도구를 배치했습니다.
- 상품 이미지를 크게 보여주고 즐겨찾기를 이미지 안에 배치했습니다. 다운로드와 폴더 정리는 카드 하단 한 줄에서 사용할 수 있습니다.
- 라이트·다크 색상, 글자 대비, 간격과 버튼 강조를 역할별로 통일했습니다. 헤더 테두리, 결과 도구 구분선과 필터 초기화 버튼은 사용하지 않습니다.
- 좁은 창에서는 사이드바가 메뉴로 전환되고 상품 배열과 검색 도구가 화면 너비에 맞춰 재배치됩니다.
- 검색·정렬 도구는 스크롤해도 상단에 남아 바로 사용할 수 있습니다.
- 버튼 누름, 카드 호버, 목록·제목·대화상자 전환에 짧은 움직임을 적용하고 운영체제의 동작 줄이기 설정을 따릅니다.
- 카드 체크박스는 평소에는 숨기고 이미지·빈 공간 클릭으로 선택합니다. 키보드로 선택 버튼에 접근할 때는 초점을 표시합니다.
- 검색어 지우기와 키보드로 조작할 수 있는 상품 선택 버튼을 추가했습니다.
- 폴더 경로는 카드에서 마지막 폴더 이름으로 간결하게 표시하며, 마우스를 올리면 전체 경로를 확인할 수 있습니다.
- 사이드바의 메뉴 영역만 스크롤하고, 좁은 창의 메뉴에서는 키보드 초점을 유지합니다.
- 대화상자 이름, 탐색 상태, 다운로드 파일 목록의 접근성 정보를 보완했습니다.
- 데모의 상품 ID를 저장 형식에 맞춰 즐겨찾기·폴더 변경 뒤에도 샘플 목록이 유지되도록 했습니다.

## 기존 데이터와 업데이트

상품, 즐겨찾기, 카테고리, 폴더 배치와 설정은 유지됩니다. 설명 분석 방식이 변경되어 다음 전체 동기화에서 지원 아바타 설명 색인을 다시 확인합니다. 기존 백업 형식도 계속 지원합니다.
