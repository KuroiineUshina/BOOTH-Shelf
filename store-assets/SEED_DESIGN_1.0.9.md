# BOOTH Shelf 1.0.9 — 화면 재설계

2026-09-08. 기존 기능을 유지하면서 HTML 배치와 스타일 체계를 다시 작성했습니다. 프레임워크 전환 없이 SEED Design 공통 Foundations·Components·Patterns를 현재 HTML·CSS·JavaScript에 적용했습니다.

## 화면 구성

- 전역 헤더: 브랜드, 빨간약, 후원, 언어, 테마, 설정.
- 사이드바: 컬렉션과 폴더 탐색. 중간 메뉴만 독립적으로 스크롤하고 너비 조절을 유지합니다.
- 본문: 제목과 동기화 → 검색·정렬·배열 조절 → 결과·선택 상태 → 상품 목록.
- 상품 카드: 큰 이미지, 이미지 안의 선택·즐겨찾기, 판매자·제목·폴더 정보, 하단 다운로드·폴더 정리.
- 다운로드: 기존 뒤집기 동작을 유지하고 파일명을 두 줄까지 표시합니다. 파일 목록은 카드 안에서 스크롤됩니다.
- 대화상자: 폴더·설정·분류·삭제·복원·통계 화면의 색상, 간격, 버튼과 입력 스타일을 통일했습니다.
- 후속 피드백: 검색·정렬 도구를 고정하고, 150ms 누름 피드백·250ms 진입 모션과 목록 전환을 적용했습니다. 카드 선택 컨트롤은 기본 화면에서 숨기되 키보드 초점으로 사용할 수 있습니다.

요청한 헤더 테두리 제거, 결과 도구 구분선 제거, 선택한 메뉴 숫자의 별도 배지 제거, 필터 초기화 제거를 유지합니다. 키보드 초점 표시는 조작 중에 제공합니다.

## 기능 보존과 검증

실제 BOOTH 계정과 분리된 로컬 데모에서 CUA 브라우저로 검증했습니다.

| 확인 | 결과 |
| --- | --- |
| 기존 자동 테스트 | 85개 통과 |
| JavaScript 문법·버전 | 통과, 1.0.9 유지 |
| 수집·저장·검색 등 핵심 모듈 | 작업 전 SHA-256과 8개 모두 일치 |
| 화면 연결점 | 기존 ID 117개 모두 유지, 중복 없음. 전역 헤더 ID 1개 추가 |
| 화면 너비 | 320, 390, 765, 980, 981, 1220, 1280, 1440px에서 가로 넘침 없음 |
| 배열·표시 | 데스크톱 4·6열, 라이트·다크, 한국어·영어·일본어 확인 |
| 검색 | 상품명·판매자·파일명 검색, 일치 파일 표시 위치, 검색어 지우기, 빈 결과, `/` 단축키 |
| 탐색·정렬 | 구매 7개·기프트 5개·무료 1개·즐겨찾기 3개, 이름순·역순 확인 |
| 선택·정리 | Space 선택, 두 상품 선택·해제, 두 카드를 폴더로 드래그해 저장 |
| 폴더·즐겨찾기 | 폴더 생성·빠른 메뉴, 여러 폴더에 동시 배치, 즐겨찾기 수 갱신 |
| 다운로드 | 뒤집기, 10개 파일 목록, 가로 넘침 없음, 데모 다운로드 안내 |
| 메뉴 접근성 | Tab 순환, Escape 닫기, 열기 버튼으로 초점 복귀, 메뉴가 열릴 때 본문·헤더 inert |
| 데이터 관리·통계 | 설정·삭제 확인창 진입과 취소, 데모 통계 계산 완료, 데모 동기화 완료 |
| 페이지 추가 로딩 | 별도 60개 fixture에서 48 → 60개 로딩. 마지막 상품 즐겨찾기 저장 후 60개 유지 |
| 브라우저 오류 | 확인한 경로에서 콘솔 오류 없음 |

색상 변수의 대비 계산은 `source-checks.json`에 기록합니다. 브라우저 조작 기록과 너비별 측정은 `browser-checks.json`, 화면 캡처는 `dist/seed-rebuild-2026-09-08/`에 있습니다. 이는 전체 접근성 적합성 인증을 의미하지 않습니다.

실제 로그인 상태의 BOOTH 수집·파일 전송은 이번 UI 검증에서 실행하지 않았습니다. 관련 로직은 변경하지 않았고 기존 회귀 테스트로 확인했습니다. 원본 기능의 백업·복원 형식, 저장 데이터와 확장프로그램 권한을 유지합니다.
