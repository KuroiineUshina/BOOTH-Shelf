BOOTH Shelf 1.0.5에서는 정렬 조작을 단순화하고, 정리 데이터를 안전하게 옮길 수 있는 백업·복원 기능을 추가했습니다. 다중선택 드래그와 다운로드 목록 검색도 함께 다듬었습니다.

## 더 단순한 정렬 스위치

- 정렬 기준을 **구매순 / 이름순** 중에서 전환하는 스위치로 정리했습니다.
- 정렬 방향은 **오름차순 / 내림차순** 스위치로 별도 전환합니다.
- 두 스위치의 값이 위아래로 도는 **원통형 전환 효과**로 바뀌어 현재 상태를 빠르게 확인할 수 있습니다.
- 시스템에서 동작 줄이기를 사용하면 회전 애니메이션을 생략합니다.

## 정리 데이터 백업과 복원

- 사이드 메뉴에서 폴더, 즐겨찾기, 상품의 폴더 배치를 JSON 파일로 백업할 수 있습니다.
- 백업 파일을 불러오면 적용할 내용을 먼저 확인한 뒤 복원합니다.
- 형식과 용량을 검사해 잘못된 파일은 적용하지 않습니다.
- 복원은 정리 데이터만 교체하며, 동기화한 상품 목록과 다운로드 정보는 건드리지 않습니다.

## 다중선택 드래그 개선

- 여러 상품이 선택된 상태에서는 어느 카드를 잡더라도 **선택해 둔 상품들만** 묶어서 이동합니다.
- 선택하지 않은 카드를 드래그 시작점으로 잡아도 그 상품이 묶음에 몰래 추가되지 않습니다.
- 클릭과 드래그 판정을 분리해 폴더 이동 후 선택 상태가 의도치 않게 바뀌지 않습니다.

## 검색·다운로드 UI 수정

- `Stay_Over_Rose_Misaki.zip`처럼 밑줄로 이어진 파일명도 `Misaki` 같은 일부 단어로 검색할 수 있습니다.
- 카드 뒷면의 다운로드 옵션이 파일명 길이나 카드마다 달라지지 않도록 좌우 폭과 버튼 배치를 고정했습니다.
- 긴 파일명은 버튼을 밀어내지 않고 카드 안에서 안전하게 생략 표시됩니다.

## 기존 데이터

1.0.4에서 업데이트해도 저장된 상품, 폴더, 즐겨찾기, 테마와 언어 설정은 그대로 유지됩니다. 새 백업 기능은 사용자가 직접 내보내기 또는 복원을 실행할 때만 저장 데이터를 변경합니다.
