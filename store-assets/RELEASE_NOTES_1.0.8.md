BOOTH Shelf 1.0.8에서는 실제로 보유한 아바타 변형을 기준으로 검색 결과를 다듬고, 빨간약 결제 금액 계산과 정리 후 스크롤 위치 복원을 보완했습니다.

## 보유한 아바타 변형 우선 검색

- 상품 제목이나 설명에 여러 지원 아바타가 적혀 있어도, 다운로드 파일명에서 특정 아바타용 변형이 확인되면 **실제로 보유한 변형만** 검색 결과에 표시합니다.
- 예를 들어 상품 전체가 미즈키와 밀티나를 모두 지원하더라도 `Milltina_...zip`만 보유했다면 밀티나 검색에는 표시되고 미즈키 검색에서는 제외됩니다.
- 여러 아바타용 파일을 함께 보유한 상품은 확인된 변형을 모두 검색할 수 있습니다.
- 다운로드 파일에 아바타명이 전혀 없는 공용 구성일 때만 상품 설명에서 확인한 지원 목록을 보조 검색 근거로 사용합니다.

## 빨간약 계산 교정

- 결제 완료·결제 확인·배송 완료 상태를 구분해 실제 결제가 확인된 주문만 합산합니다.
- 미결제·취소·환불 주문은 합계에서 제외합니다.
- 한국어·일본어·영어 결제 금액 표기와 `JPY 1,200`, `¥ 1,200`, `1,200 JPY` 형식을 더 정확하게 인식합니다.
- 상품 소계가 아니라 주문 상세의 **결제 금액** 항목을 우선해 BOOST와 배송비가 포함된 실제 결제액을 합산합니다.
- 이전 계산 캐시는 자동으로 무효화되므로 업데이트 후 빨간약을 한 번 다시 계산해 주세요.

## 정리 후 스크롤 위치 유지 보완

- 무한 스크롤로 아래쪽 상품까지 불러온 뒤 폴더에 넣거나 배치를 변경해도 이미 불러온 카드 수를 유지합니다.
- 저장소 변경으로 목록을 다시 그릴 때 현재 보이는 카드를 기준점으로 삼아 화면이 맨 위로 이동하는 현상을 줄였습니다.

## 기존 데이터

1.0.7에서 업데이트해도 저장된 상품, 즐겨찾기, 카테고리, 폴더 배치와 설명, 테마·언어·카드 배열·사이드바 너비 설정은 유지됩니다. 빨간약의 이전 계산 결과만 정확한 재계산을 위해 초기화됩니다.
