# BOOTH Shelf — Chrome 웹 스토어 등록정보

## 설명

BOOTH Shelf는 BOOTH 계정의 라이브러리·받은 기프트·무료 다운로드를 한 화면에서 검색하고 정리할 수 있는 비공식 Chromium 확장프로그램입니다.

주요 기능

- 라이브러리·기프트·무료 다운로드의 모든 페이지를 한 번에 동기화
- 상품명·판매자명·다운로드 파일명과 상품 설명의 지원 아바타로 검색
- 한 글자만 입력해도 부분 일치하는 한국어·영어·일본어 아바타 표기를 자동으로 연결하는 검색
- 공개 상품 설명의 지원 모델 구역과 연결된 원본 아바타 상품을 분석해 제목에 없는 지원 아바타도 검색
- 구매순과 이름순을 각각 오름차순·내림차순으로 조합하는 정렬
- 구매 상품, 받은 기프트, 무료 상품, 즐겨찾기 필터
- 같은 상품 페이지의 여러 아바타 버전과 구매·기프트·무료 항목을 카드 하나로 통합
- 접고 펼칠 수 있는 카테고리 아래에 최대 3계층 폴더를 구성하고 이름 변경·이동·삭제
- 폴더별 설명과 한 줄 4·5·6개 카드 배열, 조절 가능한 사이드바 너비
- 카드와 폴더 전용 우클릭 빠른 메뉴
- 카테고리·폴더·상품 배치·즐겨찾기 백업과 복원
- 상품 하나를 여러 폴더에 동시에 분류하고 체크박스로 배치 관리
- 기존 폴더 분류를 유지한 채 새 폴더에도 추가하는 드래그 앤 드롭
- 카드 클릭 다중선택과 여러 상품 묶음 드래그
- 상품 카드에서 다운로드 옵션을 확인하고 원하는 파일 다운로드
- 상품명 아래에 BOOTH 상품 종류(3D 의상, 3D 헤어 등)를 표시하고 종류별로 바로 검색
- 상품명 클릭으로 BOOTH 상품 상세 페이지 열기
- 판매자명 클릭으로 해당 판매자의 BOOTH 상점 페이지 열기
- 한국어·영어·일본어 UI, 라이트·다크·시스템 모드와 화면 애니메이션
- 스크롤 위치에 맞춰 다음 상품을 자동으로 불러오는 목록
- 결제가 확인된 주문의 실제 결제 금액 합계를 확인하는 재미용 '빨간약' 기능
- Claude Code·Codex 같은 AI 도구가 내 라이브러리를 검색·추천하고 파일을 다운로드하는 선택 기능 'AI 연결 (MCP)' (기본적으로 다운로드마다 승인)

BOOTH Shelf를 열고 '전체 동기화'를 실행하면 구매 상품, 받은 기프트와 무료 다운로드를 불러옵니다. 동기화가 끝난 뒤에는 저장된 상품을 빠르게 검색하고, 즐겨찾기와 카테고리·폴더로 분류할 수 있습니다.

개인정보와 권한

BOOTH 계정 페이지 권한과 공개 상품 페이지 권한은 관련 기능을 처음 실행할 때만 선택적으로 요청합니다. 계정 페이지 권한은 라이브러리 동기화, 다운로드 목록 조회와 빨간약 계산에 사용합니다. 공개 상품 페이지 권한은 전체 동기화 중 상품 설명과 연결된 아바타 상품 ID를 읽는 데 사용하며 로그인 정보 없이 요청합니다. 상품 정보, 검색용 다운로드 파일명·표시 용량, 설명에서 감지한 지원 아바타 ID·확인 시각, 즐겨찾기, 카테고리·폴더와 설명, 테마·언어·카드 배열·사이드바 너비 설정과 결제 합계 요약은 현재 브라우저 프로필의 로컬 확장 저장소에만 보관됩니다. 상품이 많은 라이브러리도 저장할 수 있도록 로컬 확장 저장소의 기본 용량 제한을 해제하는 저장 권한을 사용하며, 이 권한으로 추가로 수집하거나 전송하는 정보는 없습니다. 상품 설명 원문과 실제 다운로드 URL은 저장하지 않습니다. 개발자 서버, 광고 또는 분석 도구로 데이터를 전송하지 않으며 판매하지 않습니다. 앱 안의 '저장 데이터 모두 삭제' 기능으로 저장 정보와 BOOTH 접근 권한을 삭제할 수 있습니다.

AI 연결 (MCP)은 기본으로 꺼져 있으며, 사용자가 설정에서 켜고 PC에 연결 프로그램(booth-shelf-mcp)을 설치한 경우에만 동작합니다. 켤 때 네이티브 앱 통신·다운로드·오프스크린 문서 권한을 선택적으로 요청합니다. 사용자가 설정한 AI 도구에 상품명·판매자·종류·지원 아바타·파일명 같은 라이브러리 요약을 전달하며, AI 도구는 이를 해당 AI 서비스 제공자에게 보낼 수 있습니다. 다운로드 주소·상품 설명 원문·주문 정보·로그인 정보는 전달하지 않고, 파일 다운로드는 기본적으로 요청마다 사용자가 승인한 경우에만 진행하며, 사용자는 설정에서 승인 창을 끌 수 있습니다. 승인 창을 꺼도 사용자 라이브러리의 BOOTH 파일만 한 번에 최대 30개까지 받습니다.

개발자 후원 링크는 사용자가 직접 선택했을 때만 Ko-fi를 새 탭으로 엽니다. 후원 여부와 관계없이 모든 기능은 동일하게 제공됩니다.

BOOTH Shelf는 pixiv 또는 BOOTH의 공식 제품이 아닌 독립적인 오픈 소스 도구입니다.

## 개인정보 보호 탭의 권한 사용 근거

- `unlimitedStorage`: 사용자의 BOOTH 라이브러리 상품 목록, 검색용 다운로드 파일명과 지원 아바타 색인을 이 브라우저의 로컬 확장 저장소에 보관합니다. 다운로드 파일이 많은 상품을 수천 개 이상 보유하면 저장 데이터가 기본 10MB 제한을 넘어 동기화 결과를 저장할 수 없으므로 이 권한으로 로컬 저장 용량 제한만 해제합니다. 추가로 수집하거나 외부로 전송하는 데이터는 없습니다.
- `nativeMessaging`: 선택 권한입니다. 사용자가 'AI 연결 (MCP)'을 켜고 이 PC에 설치한 BOOTH Shelf 전용 연결 프로그램(booth-shelf-mcp)과만 통신해, 사용자가 설정한 AI 도구의 라이브러리 검색·파일 목록·다운로드 요청을 확장에 전달합니다. 연결 프로그램은 사용자가 직접 설치하며 이 확장 ID만 허용합니다.
- `downloads`: 선택 권한입니다. AI 연결로 요청된 사용자 라이브러리의 BOOTH 파일을 다운로드 폴더의 BOOTH Shelf 폴더에 받고(기본적으로 요청마다 승인 창에서 사용자가 허용, 사용자가 설정에서 끌 수 있음), 완료된 파일 경로를 확인해 AI 도구에 알려 주는 데 사용합니다. 기존 다운로드 기록은 읽지 않습니다.
- `offscreen`: 선택 권한입니다. AI 연결 요청을 백그라운드에서 처리할 때, 사용자의 BOOTH 라이브러리 페이지를 분석해 상품의 다운로드 파일 목록을 찾는 데만 사용합니다(서비스 워커에는 HTML 분석 기능이 없기 때문).
