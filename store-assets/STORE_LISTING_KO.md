# BOOTH Shelf — Chrome 웹 스토어 등록정보

## 설명

BOOTH Shelf는 BOOTH 계정의 라이브러리와 받은 기프트를 한 화면에서 검색하고 정리할 수 있는 비공식 Chromium 확장프로그램입니다.

주요 기능

- 라이브러리와 기프트함의 모든 페이지를 한 번에 동기화
- 상품명 또는 판매자명으로 검색
- 구매순, 이름 오름차순, 이름 내림차순 정렬
- 구매 상품, 받은 기프트, 즐겨찾기 필터
- 같은 상품 페이지의 여러 아바타 버전과 구매·기프트 항목을 카드 하나로 통합
- 최대 3계층 폴더 생성과 이름 변경·이동·삭제
- 상품 카드를 폴더로 끌어 놓는 드래그 앤 드롭 분류
- 상품 카드에서 다운로드 옵션을 확인하고 원하는 파일 다운로드
- 상품명 클릭으로 BOOTH 상품 상세 페이지 열기
- 라이트·다크 모드와 화면 애니메이션
- 완료 주문의 결제 금액 합계를 확인하는 재미용 '빨간약' 기능

BOOTH Shelf를 열고 '전체 동기화'를 실행하면 구매 상품과 받은 기프트를 불러옵니다. 동기화가 끝난 뒤에는 저장된 상품을 빠르게 검색하고, 즐겨찾기와 폴더로 분류할 수 있습니다.

개인정보와 권한

BOOTH 계정 페이지 접근 권한은 동기화, 다운로드 목록 조회 또는 빨간약 계산을 처음 실행할 때만 선택적으로 요청합니다. 상품 정보, 즐겨찾기, 폴더, 테마 설정과 결제 합계 요약은 현재 브라우저 프로필의 로컬 확장 저장소에만 보관됩니다. 개발자 서버, 광고 또는 분석 도구로 데이터를 전송하지 않으며 판매하지 않습니다. 앱 안의 '저장 데이터 모두 삭제' 기능으로 저장 정보와 BOOTH 접근 권한을 삭제할 수 있습니다.

개발자 후원 링크는 사용자가 직접 선택했을 때만 Ko-fi를 새 탭으로 엽니다. 후원 여부와 관계없이 모든 기능은 동일하게 제공됩니다.

BOOTH Shelf는 pixiv 또는 BOOTH의 공식 제품이 아닌 독립적인 오픈 소스 도구입니다.
