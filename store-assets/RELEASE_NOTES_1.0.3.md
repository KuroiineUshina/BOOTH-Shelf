이번 업데이트에서는 많은 상품을 더 빠르고 편안하게 찾을 수 있도록 검색과 정렬 경험을 다듬었습니다.

## 정렬 기능 개선

- **구매순**과 **이름순**을 별도의 드롭다운으로 분리했습니다.
- 각 정렬은 **오름차순**, **내림차순**, **끄기** 중에서 선택할 수 있습니다.
- 정렬 기준이 사라지지 않도록 구매순과 이름순 중 하나는 항상 켜진 상태로 유지됩니다.
- 현재 정렬 상태를 한눈에 알아볼 수 있도록 메뉴에 아이콘을 추가했습니다.

## 더 유연해진 검색

- 한글과 영문 자판을 잘못 선택한 채 입력해도 의도한 검색어를 함께 찾습니다.
- 한국어·영어·히라가나·가타카나 표기를 연결해 일본어 상품명 검색을 돕습니다.
- 예를 들어 `Milltina` 또는 `밀티나`를 입력하면 현재 보유 상품에 `ミルティナ`가 있을 때 검색창 아래에 **이것을 찾으셨나요?** 제안이 표시됩니다.
- 67개 주요 아바타의 자주 쓰이는 표기를 지원하며, 사전에 없는 가나 표기도 자동 음역해 검색 후보를 만듭니다.
- 검색 제안은 사용자의 현재 라이브러리와 기프트함에 실제로 존재하는 상품명 또는 판매자명만 보여 줍니다.

## 눈이 편안한 카드 애니메이션

- 글자를 입력할 때마다 모든 카드의 등장 애니메이션이 반복되던 동작을 제거했습니다.
- 검색과 맞지 않는 카드는 자연스럽게 사라지고, 남은 카드가 빈자리를 메우며 이동합니다.
- 검색어를 지우면 다시 나타난 카드가 현재 정렬 위치로 자연스럽게 들어옵니다.

## UI 개선

- 사이드 메뉴의 주요 항목에 기능을 구분하기 쉬운 아이콘을 추가했습니다.
- 정렬 드롭다운과 상태 표시를 더 명확하게 다듬었습니다.

## 기존 데이터

이번 업데이트는 저장소 구조를 변경하거나 기존 데이터를 초기화하지 않습니다. 업데이트 후에도 저장된 상품, 즐겨찾기, 폴더 구성, 테마 설정이 그대로 유지됩니다.

## 참고

- 아바타 이름 사전은 널리 사용되는 주요 표기를 중심으로 구성되어 있으며 이후에도 확장할 수 있습니다.
- 실제 검색 결과와 제안은 동기화되어 현재 브라우저에 저장된 상품 정보를 기준으로 합니다.
