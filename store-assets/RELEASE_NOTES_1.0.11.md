BOOTH Shelf 1.0.11은 전체 동기화의 대기 시간을 크게 줄이고, 빨간약 결제 금액 합계가 실제보다 적게 계산되던 문제를 수정합니다.

## 더 빨라진 전체 동기화

- 구매·기프트·무료 목록 저장이 끝나면 바로 동기화 완료로 표시하고 라이브러리를 사용할 수 있습니다. 지원 아바타 확인은 사용하는 동안 백그라운드에서 이어지며 진행 상황은 동기화 패널에 표시됩니다.
- 상품 설명을 무거운 상품 페이지 대신 BOOTH의 공개 상품 정보(JSON)로 읽어, 요청 하나당 전송량이 약 1/10로 줄고 분석도 가벼워졌습니다. 보유 상품으로 기존 방식과 결과가 같은지 확인했으며, 형식이 다르면 자동으로 기존 방식을 사용합니다.
- 연령 확인이 필요한 상품은 그동안 설명을 읽지 못해 지원 아바타가 검색되지 않고 매 동기화마다 다시 확인하던 문제도 함께 해결했습니다.
- 지원 아바타 정보의 재확인 시기를 상품마다 30~45일로 나눠, 한 달에 한 번 모든 상품을 다시 확인하느라 동기화가 길어지던 현상을 없앴습니다.
- BOOTH에 보내는 요청 간격은 그대로 유지합니다.

## 빨간약 계산 수정

- BOOTH 주문 상세 화면 위쪽에 날짜가 들어간 사이트 공지가 표시되면, 모든 주문을 같은 주문으로 잘못 인식해 한 건만 합산하던 문제를 수정했습니다.
- 이제 주문 상세 화면의 제목과 관계없이 구매 내역에서 확인한 주문 번호로 각 주문을 구분하므로, 결제가 확인된 모든 주문이 합계와 주문 수에 포함됩니다.
- 이전에 잘못 계산된 결과는 자동으로 초기화되므로 업데이트 후 빨간약을 한 번 다시 계산해 주세요.

## 기존 데이터와 업데이트

상품, 즐겨찾기, 카테고리, 폴더 배치와 설명, 지원 아바타 정보, 테마·언어·카드 배열·사이드바 너비 설정은 그대로 유지됩니다. 빨간약의 이전 계산 결과만 정확한 재계산을 위해 초기화됩니다.
