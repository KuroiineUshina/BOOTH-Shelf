BOOTH Shelf 1.0.7에서는 카드 배열과 사이드바 크기를 원하는 작업 환경에 맞게 조절할 수 있도록 화면 설정을 확장했습니다. 폴더 설명, 정리 후 스크롤 위치 보존과 간결해진 사이드바도 함께 적용했습니다.

## 카드 배열과 사이드바 크기 조절

- 정렬 버튼 옆의 3단계 슬라이더로 한 줄에 표시할 카드를 **4개·5개·6개** 중 선택할 수 있습니다.
- 숫자를 직접 표시하지 않는 간결한 조절 UI를 사용하며 5열과 6열에서는 카드 내부 간격과 버튼 크기도 함께 최적화됩니다.
- 화면이 좁아지면 기존 반응형 배열을 우선 적용해 가로 스크롤이 생기지 않습니다.
- 데스크톱에서는 사이드바 오른쪽 경계를 드래그하거나 키보드 방향키로 너비를 조절할 수 있습니다.
- 카드 배열과 사이드바 너비는 이 기기의 로컬 설정에 저장되어 다음 실행에도 유지됩니다.

## 폴더 설명

- 폴더를 만들거나 이름을 변경할 때 최대 160자의 설명을 함께 지정할 수 있습니다.
- 지정한 설명은 해당 폴더 화면의 제목 아래에 표시됩니다.
- 설명을 비워 두면 기존 기본 안내 문구가 사용됩니다.
- 폴더 설명은 정리 데이터 백업과 복원에도 포함되며 이전 형식의 백업 파일도 계속 불러올 수 있습니다.

## 정리 작업과 사이드바 개선

- 아래쪽 상품을 폴더에 넣거나 폴더 배치를 변경해도 현재 스크롤 위치가 위로 초기화되지 않습니다.
- 사이드바의 하위 추가·이름 변경·이동·삭제 버튼 묶음을 제거하고 기존 우클릭 메뉴로 동작을 통일했습니다.
- 불필요한 드래그 안내 문구와 보이는 스크롤바를 제거해 폴더 목록을 더 단정하게 정리했습니다.
- Ko-fi 후원 버튼은 헤더의 아이콘 버튼으로 옮겼습니다.
- 백업·복원·저장 데이터 삭제는 헤더의 새 **설정** 메뉴에서 관리합니다.

## 기존 데이터

1.0.6에서 업데이트해도 저장된 상품, 즐겨찾기, 카테고리, 폴더 배치, 테마와 언어 설정은 유지됩니다. 기존 폴더에는 빈 설명이 자동으로 추가되며 카드 배열은 4열, 사이드바는 기본 너비로 시작합니다. 이후 사용자가 바꾼 화면 설정은 로컬에 저장됩니다.
