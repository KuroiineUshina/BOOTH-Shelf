BOOTH Shelf 1.0.4에서는 많은 상품을 더 빠르고 편안하게 찾을 수 있도록 검색과 정렬 경험을 다듬었습니다.

## 정렬 기능 개선

- **구매순**과 **이름순**을 별도의 드롭다운으로 분리했습니다.
- 각 정렬은 **오름차순**, **내림차순**, **끄기** 중에서 선택할 수 있습니다.
- 두 정렬은 동시에 사용할 수 있으며 둘 다 끌 수는 없습니다. 함께 켜면 이름순을 먼저 적용하고 같은 이름의 상품은 구매순으로 정렬합니다.
- 현재 정렬 상태를 한눈에 알아볼 수 있도록 메뉴에 아이콘을 추가했습니다.

## 자동으로 연결되는 다국어 검색

- 한글과 영문 자판을 잘못 선택한 채 입력해도 의도한 검색어를 함께 찾습니다.
- 한국어·영어·히라가나·가타카나 아바타 표기를 자동으로 연결해 별도의 제안 선택 없이 바로 결과를 보여 줍니다.
- `밀`이나 `mil`처럼 이름의 일부만 입력해도 그 글자를 포함하는 모든 아바타 후보를 함께 찾습니다.
- 예를 들어 `Milltina`, `밀티나`, `ミルティナ` 중 어느 표기를 입력해도 같은 아바타 상품을 찾습니다.
- 68개 주요 아바타의 자주 쓰이는 표기를 지원하며, 사전에 없는 가나 표기도 자동 음역해 함께 검색합니다.

## 다운로드 파일명 검색

- 전체 동기화 때 각 상품의 다운로드 파일명과 표시 용량도 함께 읽습니다.
- 상품명에 원하는 정보가 없어도 ZIP, Unitypackage 등 실제 다운로드 파일명으로 상품을 찾을 수 있습니다.
- 검색 결과 카드에는 일치한 파일명을 표시합니다.
- 보안을 위해 실제 다운로드 URL은 저장하지 않고, 다운로드 카드를 열 때 BOOTH에서 다시 확인합니다.

## 여러 상품을 한 번에 정리

- 카드의 이미지·여백을 클릭할 때마다 상품을 선택하거나 해제할 수 있습니다. 별도의 보조 키는 필요하지 않습니다.
- 선택된 카드 하나를 폴더로 끌면 선택한 상품이 모두 함께 이동합니다.
- 썸네일 이미지에서 바로 드래그를 시작할 수 있습니다.
- 선택된 카드는 흔들리지 않고 가볍게 떠오르는 강조 효과로 표시됩니다.
- 한 카드를 선택하거나 해제해도 이미 선택된 다른 카드의 애니메이션은 다시 시작하지 않습니다.
- 드래그할 때는 선택한 카드의 실제 앞면이 살짝 어긋난 묶음으로 모여 커서를 따라갑니다.
- 카드 묶음의 경계가 사이드 메뉴에 닿으면 개수 배지와 함께 75% 크기·75% 불투명도로 천천히 바뀝니다.
- 폴더에 놓지 않고 드래그를 끝내면 선택 상태를 바꾸지 않습니다.

## 눈이 편안한 카드 애니메이션

- 글자를 입력할 때마다 모든 카드의 등장 애니메이션이 반복되던 동작을 제거했습니다.
- 검색과 맞지 않는 카드는 자연스럽게 사라지고, 남은 카드가 빈자리를 메우며 이동합니다.
- 검색어를 지우면 다시 나타난 카드가 현재 정렬 위치로 자연스럽게 들어옵니다.

## UI 개선

- 사이드 메뉴의 주요 항목에 기능을 구분하기 쉬운 아이콘을 추가했습니다.
- BOOTH Shelf에는 앱 아이콘을, 개발자 후원에는 Ko-fi 공식 컵 아이콘을 표시합니다.
- 헤더의 언어 아이콘을 눌러 한국어 → English → 日本語 UI를 순환 전환할 수 있습니다.
- 한국어·영어에는 Paperlogy, 일본어에는 M PLUS 1을 적용해 각 언어를 선명하고 자연스럽게 표시합니다.
- 테마 전환 버튼은 아이콘만 표시하도록 간결하게 정리했습니다.
- 라이트·다크 테마 전환 시 제각각 재생되던 색상 애니메이션을 제거했습니다.
- 카드 상단의 출처 배지와 선택 번호를 같은 높이로 정렬했습니다.
- 구매·선물·무료 배지는 강조색 배경과 흰색 문자로 선명하게 표시합니다.
- `더 보기` 버튼 없이 목록 끝에 가까워지면 다음 상품을 자동으로 불러옵니다.
- 구매·기프트와 함께 무료 다운로드 상품도 동기화하고 `구매 / 선물 / 무료`로 구분합니다.
- 정렬 드롭다운과 상태 표시를 더 명확하게 다듬었습니다.
- 카드의 판매자명을 클릭하면 해당 판매자의 BOOTH 상점 페이지를 새 탭에서 엽니다.

## 기존 데이터

저장 데이터 형식은 자동으로 새 버전으로 변환됩니다. 업데이트 후에도 저장된 상품, 즐겨찾기, 폴더 구성, 테마 설정은 그대로 유지됩니다. 다운로드 파일명 검색은 업데이트 후 **전체 동기화**를 한 번 실행하면 사용할 수 있습니다.

## 참고

- 아바타 이름 사전은 널리 사용되는 주요 표기를 중심으로 구성되어 있으며 이후에도 확장할 수 있습니다.
- `海咲-Misaki-`의 `미사키 / Misaki / ミサキ / みさき / 海咲` 표기를 자동으로 연결합니다.
- 실제 검색 결과는 동기화되어 현재 브라우저에 저장된 상품과 다운로드 파일 정보를 기준으로 합니다.
